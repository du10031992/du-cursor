# MepPanel v0.1.0

**License Control MVP** — 2026-08-04

## Có gì trong bản này

1. License Server kiểm soát Active/Block theo SĐT  
2. Mỗi SĐT chỉ 1 máy; chuyển máy cần Admin mở  
3. Mở/khóa chức năng plugin `MEPDB`, `MEPHVAC`  
4. Client AutoCAD gate lệnh theo license  

## Tạo gói zip

Từ thư mục gốc repo:

```bash
./scripts/pack-release.sh 0.1.0
```

- `MepPanel-LicenseServer-v0.1.0.zip`
- `MepPanel-v0.1.0.zip`
