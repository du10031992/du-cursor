# MEP Cabinet Renderer — Pillow photoreal (mac dinh)

Renderer ghép ảnh PNG thiết bị AI lên layout tủ DIN.

## Demo

```bash
python3 render_cabinet.py --demo --quality photoreal --output cabinet.png
```

Mac dinh: `--mode interior` + `--quality photoreal`.

## Cai vao plugin

```powershell
.\scripts\install-renderer-devices.ps1
```

## Anh thiet bi (`devices/`)

PNG AI catalog (MCCB, MCB, contactor, relay, pilot 3P, SPD, ...).
